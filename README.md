# 🚍 Sistema de Gestión de Rutas Escolares

¡Bienvenido al Sistema de Rutas Escolares! Esta es una plataforma web diseñada para facilitar la visualización, control y registro de los estudiantes en los diferentes recorridos de transporte escolar.

El objetivo principal de este proyecto es ofrecer una interfaz intuitiva y amigable tanto para los padres de familia como para los administradores del transporte, asegurando que la información de las rutas y los estudiantes esté siempre al alcance de la mano.

## 🚀 Funcionalidades Detalladas

El proyecto está dividido en 3 secciones clave, cada una con un propósito específico:

### 🏠 1. Landing Page (Página de Inicio)
* **Presentación del Servicio:** Una sección atractiva con imágenes y textos que explican la seguridad, puntualidad y cobertura del transporte escolar.
* **Sección de Beneficios:** Iconos y tarjetas informativas que destacan por qué elegir este sistema de rutas (conductores certificados, monitoreo, etc.).
* **Navegación Intuitiva:** Un menú superior (*Navbar*) que permite desplazarse rápidamente entre el inicio, la lista de rutas y el formulario de inscripción.

### 📝 2. Módulo de Registro de Estudiantes
* **Formulario de Inscripción:** Recopila los datos esenciales del estudiante (Nombre completo, edad, grado, dirección) y del acudiente (Teléfono de contacto).
* **Asignación de Ruta:** Permite seleccionar a qué ruta específica se desea inscribir al alumno.

### 📍 3. Pestaña de Rutas Escolares
* **Visualización de Recorridos:** Muestra de forma clara los diferentes trayectos (por ejemplo: Ruta Norte, Ruta Sur, Oriente, etc.).
* **Información de Interés:** Cada ruta detalla datos cruciales como la hora de salida, los puntos principales de recogida, el conductor asignado y el estado de los cupos.
* **Diseño Adaptable:** La información está organizada en tarjetas o tablas dinámicas para que sea muy fácil de leer.

## 🛠️ Tecnologías Utilizadas

Para el desarrollo de esta aplicación se utilizaron las siguientes herramientas:

* **HTML5:** Para construir la estructura y el contenido de todas las páginas y el formulario.
* **CSS3:** Para el diseño visual, los colores, la tipografía y la distribución del espacio.
* **JavaScript:** Para darle interactividad a la página, y procesar los datos del formulario de registro y asignación de rutas.
